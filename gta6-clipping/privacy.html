Privacy Policy

Last updated: 17 November 2026

This policy covers Clip City, a personal tool used only by the owner of the Clip City YouTube channel to upload and manage that channel's own videos.

YouTube API Services

Clip City uses the YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Information handled through the YouTube API Services is also covered by the Google Privacy Policy.

What it accesses

The tool requests two Google permissions for the owner's own channel:

  • youtube.upload: to upload the channel's Shorts.
  • youtube: to change an uploaded video from private to public after the owner approves it.

It does not read, collect or store data about any other person, including viewers or commenters, and it does not access the owner's email, contacts, files or viewing history.

What it stores

For the channel's own videos, the tool keeps the video ID, title and publishing status in the owner's private GitHub repository so it can avoid duplicate uploads. Any view statistics it reads in future are refreshed or deleted within 30 days.

How credentials are stored

The token needed for uploads is stored as an encrypted secret in the owner's private GitHub repository and is used only to upload and publish the channel's videos. It is never sold, shared or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies

Clip City and these pages set no cookies and use no analytics or advertising trackers. The pages are hosted on GitHub Pages; see the GitHub Privacy Statement for how GitHub handles visits.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

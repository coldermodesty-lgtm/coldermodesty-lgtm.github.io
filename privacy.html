Privacy Policy

Last updated: 14 November 2026

This policy covers DHH Decoded Uploader, a personal tool used only by the owner of the DHH Decoded YouTube channel to upload that channel's own videos.

What it accesses

The tool requests one Google permission: youtube.upload, which lets it upload videos to the signed-in owner's YouTube channel. It does not read, collect or store data about any other person, and it does not access the owner's email, contacts, files or viewing history.

How credentials are stored

The access token needed for uploads is stored as an encrypted secret in the owner's private GitHub repository and is used only to upload videos. It is never sold, shared or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Videos are uploaded through the YouTube API Services, and the Google Privacy Policy applies to them.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
